Understanding DNS Records

Learn what each DNS record does.

A Record

Maps a domain name to an IPv4 address. It helps computers locate websites.

AAAA Record

Maps a domain name to an IPv6 address. It supports the newer Internet Protocol version.

MX Record

Identifies the mail servers responsible for receiving emails for a domain.

NS Record

Identifies the name servers responsible for a domain's DNS information.

CNAME Record

Creates an alias that points one domain name to another canonical domain name.

TXT Record

Stores text information associated with a domain, including verification and email security policies.
